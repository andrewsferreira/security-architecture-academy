## Regras de integridade

Estas regras valem para todo o projeto e não admitem exceção:

1. **Nada é anunciado como pronto antes de estar pronto.** Status refletem o estado real e são verificados automaticamente.
2. **Nenhum dado real.** Sem credenciais, dados pessoais, informações de empregadores ou sistemas de terceiros — nem em exemplos.
3. **Nenhuma afiliação implícita.** Organizações citadas são referências; seus logotipos não são usados.
4. **Toda afirmação técnica é rastreável** a uma fonte, ou declarada explicitamente como opinião.
5. **Acessibilidade é requisito**, não melhoria.
