# Avaliações

As avaliações verificam **competências**, não memorização. Elas pedem que o estudante analise diagramas, encontre erros, escolha controles, compare propostas e defenda decisões — as mesmas tarefas de um arquiteto de segurança.

## Formatos de questão

| Formato | O que verifica | Exemplo |
|:---|:---|:---|
| Fundamentos | Conceitos e terminologia | Diferença entre padrão e baseline |
| Situacional | Aplicação a um cenário | Qual controle compensatório para um sistema sem suporte |
| Análise de diagrama | Leitura de arquitetura | Quais fluxos cruzam trust boundaries sem autenticação |
| Identificação de erros | Senso crítico | O que está errado neste ADR |
| Seleção de controles | Raciocínio por camadas | Combinação mínima de controles para um risco |
| Justificativa de decisão | Argumentação | Defender a alternativa B diante de restrição de orçamento |
| Estudo de caso executivo | Comunicação com o negócio | Resumo de uma página para o CISO |

## Regras de toda questão

- Alternativas **plausíveis**: distratores representam erros que profissionais realmente cometem.
- Gabarito com **resposta correta, explicação técnica, justificativa de cada alternativa incorreta** e a aula ou referência relacionada.
- **Gabaritos em arquivos separados**, na seção [Gabaritos](answers/diagnostic-fundamentals.md), para que a avaliação possa ser feita sem ver as respostas.
- Questões **originais**, em português, com terminologia técnica em inglês.

## Critérios de aprovação

| Avaliação | Mínimo para avançar |
|:---|:---|
| Diagnóstica | 70% em cada seção |
| De módulo | 70% no total e nenhuma questão dissertativa avaliada como *Insuficiente* |
| Intermediária e final | 70% no total |
| Estudos de caso e projeto final | Nenhum critério *Insuficiente* na [rubrica](rubrics.md) |

O resultado não é uma nota de certificação: é um **sinal de progresso**. Quem não atinge o mínimo recebe, no gabarito, a indicação das aulas a revisar.
