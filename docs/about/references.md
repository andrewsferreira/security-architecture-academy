# Referências

Estas são as **fontes primárias previstas** para fundamentar o conteúdo. Cada aula listará as referências específicas que utilizar, com versão e data de consulta.

!!! note "Sem afiliação"

    A citação de uma organização não implica afiliação, patrocínio ou endosso. Logotipos de terceiros não são utilizados no projeto.

## Normas e frameworks

| Organização | Referências previstas | Domínios |
|:---|:---|:---|
| [NIST](https://www.nist.gov/cybersecurity) | Cybersecurity Framework (CSF), SP 800-53, SP 800-207 (Zero Trust), SP 800-37 (RMF), SP 800-63 (Digital Identity) | GRC, Zero Trust, IAM |
| [ISO/IEC](https://www.iso.org/standard/27001) | ISO/IEC 27001, ISO/IEC 27002, ISO 31000 | GRC, riscos |
| [CIS](https://www.cisecurity.org/controls) | CIS Critical Security Controls, CIS Benchmarks | Controles, hardening |
| [OWASP](https://owasp.org/) | ASVS, Top 10, API Security Top 10, Threat Modeling | Application Security |
| [Cloud Security Alliance](https://cloudsecurityalliance.org/) | Cloud Controls Matrix (CCM) | Cloud, multicloud |
| [MITRE](https://attack.mitre.org/) | ATT&CK, D3FEND | Detecção, threat modeling |
| [The Open Group](https://www.opengroup.org/togaf) | TOGAF | Enterprise Architecture |
| [SABSA Institute](https://sabsa.org/) | SABSA | Enterprise Security Architecture |

## Política de referências

- Preferir a **fonte primária** (norma, publicação oficial, RFC) a artigos secundários.
- Informar **versão ou revisão** quando a referência for versionada (por exemplo, *NIST SP 800-53 Rev. 5*).
- Indicar se o recurso é **gratuito ou pago**.
- Revisar links e versões periodicamente — os links externos são verificados semanalmente pelo CI.

O formato de citação: autor ou organização, título em itálico, versão ou ano, link e se o acesso é gratuito ou pago.
