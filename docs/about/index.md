# Sobre o projeto

A **Security Architecture Academy** é uma iniciativa educacional aberta para quem quer aprender — ou ensinar — Arquitetura de Segurança da Informação de forma estruturada, do fundamento à decisão corporativa.

## Por que este projeto existe

Arquitetura de segurança costuma ser aprendida de forma fragmentada: um framework aqui, uma certificação ali, a documentação de um provedor de cloud acolá. O resultado é conhecimento técnico profundo em ilhas, mas pouca prática em **conectar** negócio, risco, identidade, rede, dados e aplicações em uma arquitetura coerente.

Esta formação existe para oferecer, em português e gratuitamente:

- **Uma sequência**: cada módulo declara o que pressupõe e o que habilita.
- **Uma linguagem comum**: terminologia técnica em inglês, explicada em português, aplicada de forma consistente.
- **Um raciocínio arquitetural**: decisões com trade-offs explícitos, registradas e revisáveis — e não listas de controles.

## Princípios

Fundamentado
:   Afirmações técnicas são rastreáveis a normas, frameworks ou documentação oficial. Opinião, boa prática e requisito normativo são diferenciados explicitamente.

Honesto sobre o estado
:   Conteúdo só é marcado como publicado depois de revisado. O que está planejado aparece como planejado.

Neutro em relação a fornecedores
:   Conceitos vêm antes de produtos. Quando um provedor é usado como exemplo, a escolha é didática, não uma recomendação comercial.

Seguro por padrão
:   Exemplos e laboratórios usam ambientes e dados fictícios. Nenhuma credencial, dado pessoal ou sistema real é utilizado.

Acessível
:   Contraste adequado, descrições textuais para diagramas e navegação por teclado fazem parte do padrão de qualidade.

## Para quem é

- Profissionais de segurança que querem evoluir para arquitetura.
- Engenheiros de software, cloud e infraestrutura que tomam decisões com impacto em segurança.
- Arquitetos, gestores e CISOs que buscam uma referência estruturada para formar equipes.

## Independência

Este é um projeto independente, mantido por uma pessoa e aberto a contribuições. **Não há afiliação, patrocínio ou endosso** de nenhuma organização citada — como NIST, ISO, ISC2, OWASP, CSA, AWS, Microsoft ou Google. Nomes dessas organizações aparecem apenas como referência bibliográfica.

A formação **não emite certificados** e não substitui programas oficiais de certificação.
