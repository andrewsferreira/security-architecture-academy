# Laboratórios

Os laboratórios demonstram **aplicação arquitetural**, e não apenas a administração de ferramentas. Eles priorizam execução local, ferramentas open source e nenhum custo obrigatório.

!!! danger "Regras de todos os laboratórios"

    - Execute apenas em ambiente próprio e isolado, criado para estudo.
    - Use somente dados sintéticos.
    - Laboratórios em cloud são sempre **opcionais**, com custos potenciais e limpeza descritos. *Free Tier* não garante custo zero.
    - O status **executado e testado** só é atribuído depois de uma execução real, registrada na própria página do laboratório com a data e a saída obtida.
